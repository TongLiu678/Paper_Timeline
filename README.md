# 论文投稿时间表 · Paper Timeline

一个面向 AI/NLP、AI Infra、EDA、操作系统和形式化方法研究者的投稿时间表。输入研究方向可查找相关会议、匹配依据和具体投稿节点；也可以按时间排序、切换月历、搜索会议、按领域筛选，并将已公布的节点导出为 `.ics` 日历文件。

**在线查看：** https://tongliu678.github.io/Paper_Timeline/

## 日期口径

数据于 **2026-09-25** 按会议或主办方官方页面核对。每个已公布节点在 [`src/data`](src/data) 中保留原时区和来源链接；页面只在官网注明具体时刻时换算为北京时间。官网只给日期的节点按原日期显示，日历导出为全天事件，不附会精确截止时刻。

主会的摘要、论文全文、ARR 投稿、会议 commit 和多轮次是不同节点。某届已截稿、下一届尚未公布时，页面显示“待公布”，往届官方日期只作历史参考。DATE 的常规论文与特别轨道分别标明；DAC 2027 官网同一页的 FAQ 与正文存在全文日期冲突，页面显式提醒复核。USENIX ATC 已在 2025 年后结束，另列新的 ACM SIGOPS ATC。

截止日期可能由会议主办方调整。实际投稿前，请点击相应节点的官方 CFP 再次核对。

## 研究方向匹配

输入中文或英文方向，例如“大模型推理”“自然语言处理”“EDA”“形式化验证”。匹配使用 [`src/topic-data.js`](src/topic-data.js) 中人工整理的主题和同义词，按核心方向、相关方向和下一官方节点排序；结果会列出会议范围简介、匹配依据、当前状态及全部已记录投稿节点。它不预测录用概率，也不会为未公布的届次生成日期。部分会议的下一届 CFP 尚未发布，其范围简介依据最近可用的官方页面；结果中的会议说明会标注这一情况。

## 本地运行

无需安装依赖。用任意静态服务器从仓库根目录提供页面，例如：

```bash
python3 -m http.server 8765
```

然后打开 http://localhost:8765/ 。数据与日期逻辑检查：

```bash
npm run check:data
npm test
```

## 更新会议

在 [`src/data`](src/data) 的对应领域文件中更新会议。每个截止节点保留官网原日期、原时区、链接；只有官网给出明确时刻时才填写带时区的 `at`。未知日期保留为空，不根据上届自动推算。更新后运行上述两项检查，推送到 `main`，GitHub Actions 会重新发布 GitHub Pages。

若要调整方向匹配，请同步更新 `src/topic-data.js` 的同义词、会议简介及核心/相关主题。`npm run check:data` 会检查每场会议都有研究方向档案，且主题引用有效。

此项目收录的是用户关注会议的投稿机会，不提供论文录用率或会议评级。页面中的类别只用于筛选。
